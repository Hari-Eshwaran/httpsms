💡 How this Gateway works:

When you click Send SMS, the server queues the message. In a live setup, a Firebase push triggers the Android phone to fetch the message and call Android's native SmsManager.sendTextMessage(). In this simulator mode, the full delivery lifecycle (Pending ➔ Sending ➔ Sent ➔ Delivered) is simulated with real timing!

Gateway Mode & Connection

Simulator mode runs self-contained without needing physical phone setup or external keys.
Use https://api.httpsms.com or self-hosted http://localhost:8000.
Required only for Live Mode to authenticate requests.

Programmatic Code Snippets

cURL — Send SMS
curl -X POST http://localhost:3000/v1/messages/send \
  -H "Content-Type: application/json" \
  -d '{
    "from": "+18005550199",
    "to": "+18005550100",
    "content": "Hello Sarah, verification code: 8201",
    "sim": "SIM1"
  }'
Node.js Client
const { HttpSmsClient } = require('./sms_client');
const client = new HttpSmsClient({ baseUrl: 'http://localhost:3000' });

await client.sendSMS({
  to: '+18005550100',
  content: 'Hello from Node!'
});
